# True Luck investor page

Single-page site. Everything is in `index.html` (logo and photo are embedded).

## Publish with GitHub Pages
1. Upload `index.html`, `.nojekyll` and this file to the root of the repository.
2. Repository Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site appears at `https://<user>.github.io/<repository>/` after a minute or two.

## Notes
- The Figtree font loads from Google Fonts and Three.js from jsDelivr, so the page needs a network connection.
- Contact details are in three places in `index.html`: search for `info@thedqb.com` and `eostechnology.digital`.
